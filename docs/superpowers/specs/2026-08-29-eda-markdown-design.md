# EDA Markdown Design

## Goal

Make the EDA section of `Research.ipynb` readable as a concise analytical report by moving every substantive explanatory comment from code cells into Markdown cells.

## Scope

The existing calculations and visualizations remain unchanged. The EDA will be organized into five short subsections: target-class balance; missing values and duplicates; categorical features; numerical features; and feature correlations.

Each conclusion will follow the approved pattern: what was examined, the observation, and the resulting decision for preprocessing or feature engineering. Text will be concise, but no shorter in substance than the original comments.

## Out of scope

No data transformations, model changes, new analysis, or plot changes are included.
