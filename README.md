# Mushroom Classification

Исследование датасета грибов: разведочный анализ данных, подготовка признаков,
проверка гипотез и бинарная классификация грибов на съедобные и ядовитые.

## Датасет

Использован датасет [Mushroom Classification](https://www.kaggle.com/datasets/uciml/mushroom-classification/data)
из UCI Mushroom Dataset. В проекте он сохранён в `data/mushrooms.csv`.

Датасет выбран потому, что он содержит 8 124 объекта, целевой бинарный признак
`class` и 22 категориальных признака, описывающих внешний вид гриба. Он
подходит для полного цикла исследования: EDA, обработки пропусков, кодирования
категорий, обучения моделей, отбора признаков и сравнения метрик.

Класс `e` обозначает съедобный гриб, класс `p` — ядовитый. В ноутбуке целевой
признак закодирован так: `e → 0`, `p → 1`.

## Гипотезы до начала работы

1. Классы достаточно сбалансированы: у хороших моделей accuracy и F1 будут
   близки.
2. Признаки ножки содержат достаточно информации для качественной
   классификации.
3. Неглубокое дерево решений не уступает неограниченному дереву по F1.
4. `bruises` — важный признак и входит в top-5 по важности.
5. Пятнадцати лучших исходных признаков достаточно: качество модели на top-15
   будет близко к качеству модели на всех признаках.

## Краткие результаты

- Наиболее частая категория и отдельная категория `missing_value` показали
  одинаковый средний F1 `0.9994`; для дальнейшего моделирования выбрана
  наиболее частая категория как более простая стратегия.
- Logistic Regression на всех признаках получила средний F1 `0.9994`; только
  на признаках ножки — `0.7876`; только на `bruises` — `0.7604`.
- Decision Tree с глубиной 5 и без ограничения глубины показали одинаковый
  средний F1 `0.9997`. Неглубокого дерева для этих данных достаточно.
- После `GridSearchCV` лучшей стала Logistic Regression с `C=100` и средним
  F1 `1.0000` на кросс-валидации.
- Финальная Logistic Regression на тестовой выборке получила accuracy, precision,
  recall, F1 и ROC-AUC, равные `1.0000`.
- `bruises` информативен сам по себе, но занял 20-е место по permutation
  importance и не вошёл в top-5.
- Модель на top-15 признаках и модель на всех признаках получили одинаковый
  средний F1 `1.0000`; top-15 признаков достаточно для этого эксперимента.

  
## Что сделано в ноутбуке

- EDA: размер датасета, типы признаков, дубликаты, пропуски, баланс классов,
  распределения и связи Cramér's V;
- подготовка данных: `?` заменяется на `NaN`, константный `veil-type`
  исключается, пропуски в `stalk-root` обрабатываются внутри pipeline;
- сравнение трёх стратегий для пропусков: удаление строк, наиболее частая
  категория и отдельная категория `missing_value`;
- one-hot кодирование категориальных признаков;
- сравнение Logistic Regression на признаках ножки, всех признаках и только на
  `bruises`;
- сравнение Decision Tree с `max_depth=5` и без ограничения глубины;
- подбор гиперпараметров обеих моделей через `GridSearchCV`;
- отбор top-15 исходных признаков по Cramér's V;
- permutation importance и матрица ошибок финальной модели.

Для сравнения моделей применяются стратифицированная 5-fold кросс-валидация и
метрики accuracy, precision, recall, F1 и ROC-AUC. Основная метрика — F1 для
класса ядовитых грибов.
