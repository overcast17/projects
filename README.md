# Mushroom Classification

Исследование датасета грибов: EDA, подготовка данных, проверка гипотез и
бинарная классификация съедобных и ядовитых грибов.

Основной файл проекта — [research.ipynb](research.ipynb).

## Датасет

Использован датасет [Mushroom Classification](https://www.kaggle.com/datasets/uciml/mushroom-classification)
из UCI Mushroom Dataset. Его копия находится в `data/mushrooms.csv`.

Датасет содержит 8 124 объекта, 22 категориальных признака и целевой столбец
`class`. Он выбран, потому что позволяет последовательно выполнить EDA,
обработку пропусков, кодирование категорий, обучение моделей, подбор
гиперпараметров и отбор признаков.

`e` означает съедобный гриб, `p` — ядовитый. В ноутбуке ядовитый гриб
закодирован как положительный класс: `p → 1`.

## Гипотезы до начала работы

1. Классы достаточно сбалансированы: у хороших моделей accuracy и F1 будут
   близки.
2. Признаки ножки содержат достаточно информации для качественной
   классификации.
3. Неглубокое дерево решений не уступает неограниченному дереву по F1.
4. `bruises` — важный признак и входит в top-5 по важности.
5. Пятнадцати лучших исходных признаков достаточно: качество модели на top-15
   будет близко к качеству модели на всех признаках.

## Результаты

Все результаты кросс-валидации получены на обучающей выборке с помощью
стратифицированной пятикратной кросс-валидации. Положительный класс — ядовитый
гриб. Основная метрика — F1; также рассчитаны accuracy, precision, recall и
ROC-AUC.

| Гипотеза | Статус | Ключевой результат | Вывод |
|---|---|---|---|
| H1 | Подтвердилась | На тесте accuracy = 1.0000, F1 = 1.0000 | Результат согласуется с близким балансом классов, выявленным в EDA |
| H2 | Частично подтвердилась | Признаки ножки: F1 = 0.7876; все признаки: F1 = 0.9994 | Признаки ножки полезны, но не заменяют полный набор |
| H3 | Подтвердилась | Глубина 5: F1 = 0.9997; неограниченное дерево: F1 = 0.9997 | Неглубокое дерево не уступает сложному |
| H4 | Не подтвердилась | Только `bruises`: F1 = 0.7604; ранг importance = 20 | Признак информативен сам по себе, но не входит в top-5 |
| H5 | Подтвердилась | Top-15: F1 = 1.0000; все признаки: F1 = 1.0000 | Пятнадцати признаков достаточно для сохранения качества |

## Обработка пропусков

Пропуски встречаются только в `stalk-root`; исходно они обозначены символом
`?`. Сравнивались три стратегии:

| Стратегия | Средний F1 | Результат |
|---|---:|---|
| Удаление строк с пропусками | 0.9988 | Снижает число доступных объектов |
| Самая частая категория | 0.9994 | Выбрана для дальнейшего моделирования |
| Отдельная категория `missing_value` | 0.9994 | Качество совпало со стратегией моды |

Для всех моделей пропуски заполняются **внутри pipeline**. Это исключает
утечку данных: значение для заполнения вычисляется отдельно на обучающей части
каждого фолда.

## Подбор гиперпараметров

Для Logistic Regression и Decision Tree выполнен `GridSearchCV` со
стратифицированной пятикратной кросс-валидацией. Критерий выбора — F1 для
класса ядовитых грибов.

| Модель | Лучший результат CV F1 | Итог |
|---|---:|---|
| Logistic Regression | 1.0000 | Выбрана финальной моделью; лучший `C = 100` |
| Decision Tree | 0.9997 | Немного уступила Logistic Regression |

## Финальная модель

Финальная модель — Logistic Regression с обработкой пропусков наиболее частой
категорией и one-hot кодированием. Она обучена на всех признаках обучающей
выборки, кроме константного `veil-type`.

На отложенной тестовой выборке из 1 625 объектов получены результаты:

| Метрика | Значение |
|---|---:|
| Accuracy | 1.0000 |
| Precision | 1.0000 |
| Recall | 1.0000 |
| F1 | 1.0000 |
| ROC-AUC | 1.0000 |

Матрица ошибок:

```text
                    Предсказано: съедобный  Предсказано: ядовитый
Фактически: съедобный            842                        0
Фактически: ядовитый               0                      783
```

Идеальное качество на этом датасете связано с высокой разделимостью классов и
не означает, что модель безопасно применять для распознавания реальных грибов.
